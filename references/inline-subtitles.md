# V24：普通整句 → 真词放大 → 句末保持

这是语音字幕的独立要求，颜色、粗体、侧栏、主画面大字或图解均不能替代。按真实发言选择有意义的词或短语，不按固定间隔、每句一词或每词放大凑数。

## 状态不变量

1. 整条字幕在自己的开始时刻，以普通字号与自然字距完整显示。
2. 到该词实际发声锚点才开始放大。相邻字只按当前可见字宽平滑让位，不能提前预留放大空槽。
3. 读序与句子对齐保持稳定，不能让后字穿过关键词、先跳位置或挤出画幅。
4. 完成态一直保持到整条字幕最后可见帧，再整条退出；不做yoyo或句末提前缩回。
5. 下一条独立初始化自己的普通态。顺序播放、随机seek、反向seek、分段渲染得到同一个时刻的相同状态。

## 组件集成

`scripts/inline-emphasis.mjs`抽取自已选工程的绝对时间实现，无人物、产品、字体和项目时码。导入 `createInlineEmphasis`，在 `document.fonts.ready`完成、字幕根节点已经有实际字体后调用。

组件时间单位为秒，统一从最终输出帧与当前fps转换；不能混入源片秒、毫秒或未重映的旧输出秒。

```javascript
const caption = createInlineEmphasis(root, {
  tokens: ['先看', '任务', '，再选工具。'],
  keywordIndex: 1,
  captionStart: 3,
  captionEnd: 6,
  anchorTime: 3.8,
  emphasisDuration: 0.24,
  scaleTo: 1.4,
  centerX: 960,
  normalColor: '#fffaf2',
  emphasisColor: '#f1cc72'
});
// 在主时间轴每次seek／渲染帧时调用；不是播放计时器。
caption.render(currentTime);
```

tokens是无空洞的真实文本片段，标点与自然空格留在相邻片段中，不能先把关键词槽做大；片段拼回完整字幕。组件按测得的普通字宽计算每帧总宽，关键词变宽时两侧一起维持整句居中。它只负责单行行内几何与颜色，不负责转写、词锚点、换行、字幕底部位置、字体授权或播放器时钟。

同条通常选择一个短语；需要多次强调或双行时扩展状态模型并重新检查，不用复制单行组件去堆重叠句。先按正常字号排短句，放大后的总宽也应在安全区；必要时按语意重新断句，不能靠压扁字形或缩到不可读掩盖溢出。双语是本期内容选择，用户已选单语时不自动加英文；中英同时出现时明确主次与安全间距。

初始anchor可能恰在captionStart，此刻progress=0，首帧仍为完整普通态；后续帧随真实发声增长。动画必须在字幕退出前完成并留下完成态。字体、字号、文本、画幅或换行变化后重新测量／建立组件；不要沿用旧字宽。

## 实际导出检查

每个强调至少覆盖：放大前、放大中、完成态、最后可见帧、下一条。全量自动采帧可检查几何，但仍需在实际视频以1倍、手机宽观看代表性长句、短句、左右端关键词和剪口附近；修改过的强调逐个看。确认真实词同步、邻字平滑、无碰撞／裁切、句末不复位、下一句普通态。

另外验证随机seek与跨分段起点，尤其分段直接从放大完成之后开始时应立即得到完成态。记录文件hash、时间范围、倍速、显示宽度、观察结果及听力限制；不能将源码、静帧、全解码或浏览器正在播放等同于实际观看／耳听。
