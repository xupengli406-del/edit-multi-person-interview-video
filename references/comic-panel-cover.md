# 已选中央漫画分格封面

本Skill的默认封面是用户已选择的**厚黑漫画分格＋中央标题信息牌**。完整制作时直接完成，不再次把漫画、真人摄影、左人右文等方案交给用户选；后续明确指令仍可覆盖默认。视频中的两行Header是另一层信息，不能因封面标题改为一行而改动视频Header。

## 视觉与内容合同

- 画格连成一张完整画面：用粗黑、不等宽、略带斜切的分隔组织人物近景及少量相关辅助场景。人物分布围绕连续的中央深色信息牌；有头、肩、动作与目光的关系，三个人不是三个等宽长条，也不是散放拍立得。人数由当期实际嘉宾决定，不凭模板补人或复制一个人。
- 人物采用可识别的漫画插画处理，粗墨线、明暗分块和细腻手绘质感同时成立。以本期原片中的清楚摄影帧或用户确认的身份照片为锚，保持五官、年龄、发型及明确服装特征；生成封面不能反过来成为下一条的身份参考。人脸不像、重影、手腕或持麦出错时修主视觉，不能用文字遮住错误。
- 已选色彩关系是暖橙／蜂蜜木色、珊瑚色与冷蓝／深炭对照；按本期场景调整色值，使人物肤色自然。辅助画格只表现与本题有关的工具、环境或动作，不为填格堆装饰。游戏封面参考只迁移画格和插画语言，不照搬其商标、角色、枪车或题材。
- 中央牌的唯一领读项是本期**明确主题＋可兑现的观看理由**。先判断目标观众正在困惑什么、看完能拿走什么，再从实际对话提炼完整问题或主张，作者经历与结果只作有价值的证据，副文没有独立补充价值就省略。不能只用“只留几个”“太强了”等脱离具体题材的抽象钩子；不虚构时长、排名、效果、能力或官方背书。下一条不能照抄本期题目、嘉宾数或产品清单。
- 信息顺序固定为主标题 → 必要副文 → 本期真实产品／主题标识的一组。主标题最大，主副项光学对齐，文字与Logo分别有适配的内外距；题目优先自然一行，题目长时按完整词组自然换行，重新安排牌高、字号和间距。Logo不围成左右两列挤出文字槽；默认整齐单排，数量较多时先选真正相关者，再合理分组。产品标识数量不是固定五枚，没有相关产品时不强塞Logo；被讨论但未被推荐的产品不能混作推荐名单，也不暗示每个人推荐了整组产品。
- 真实字体保持自然宽高，优先获授权的Noto Sans SC／CJK SC Black 900或清楚的同类替代。白色主字、必要黑轮廓与短阴影服务辨认；禁止单轴拉宽、压扁或透视凑宽。Logo同样保持原比例，以contain方式放进合理容器。先量实际字形、轮廓和阴影，再确定字号与位置。牌内留白用于阅读层级与呼吸，不是机械填满率；不能一边挤字一边空出无用途大块区域，也不能把字号一味缩小迁就旧模板。

## 制作顺序与可复用输入

1. 从最终成片提炼主题、受众、问题／收益、必要副文和相关产品清单。建立本期人物身份参考与官方Logo来源表；检查标题承诺能在片中兑现。
2. 先规划三种画幅的画格、中央阅读区、脸／手／道具保护区，再取得无字背景。新主视觉按图像生成工具的正常工作流制作；本期已有已认可无字底图时复用，不反复生成人脸。
3. 将无字背景与真实人物身份参考作为独立输入，生成无字漫画人物主视觉。明确每人是谁、各出现几次、所在画格、动作及标题保护区；不让生成模型处理中文、官方Logo或事实界面。实际看身份、手、光线、画格和空白标题区后才进入排字。
4. 用确定性文字与真实Logo图层排中央牌。SVG标识可由当前可用工具按目标尺寸或更高分辨率转换为透明PNG，保留原官方文件与来源指纹；不能把小尺寸糊图放大冒充清晰标识，也不以临摹、字母圆圈或生成假标识替代。允许原生SVG重新组织已有漫画人物画格，保持同一漫画脸，不能将整张竖图硬裁或拉伸成横图。
5. 三比例分别完成：3:4可用1242×1656，4:3可用1600×1200，16:9可用1920×1080。逐比调整人物尺度、画格宽度和标题牌，不将一个比例通过当成全部通过。

先内部做一个比例、自查再扩完整三比例，不把内部检查变成反复向用户批准的门槛。封面主题、四平台标题、第一真实三秒与正文应承诺同一件可兑现的事；需要改封面时只改所要求的层，不能顺手改已接纳电影或原声。不要添加制作方日期、状态词、无意义注释、账号胶囊或页码，除非用户明确需要。

[无私人素材的布局起点](../assets/comic-cover-preset.json)记录所选阅读顺序和三比例参考区域；坐标只是起点，遇到不同题目、人数或画面必须重新测量。`scripts/cover_overlay.py`可在已排好的原生画幅底图上渲染自然字体与PNG Logo图层并生成测量；它不生成人像或画格，也不判断吸引力。工具、字体及生成服务从当前环境发现，不写死某台电脑路径。

## 原图、手机与发布包的闭环

逐比查看原图及约300×400、400×300、400×225的手机缩略图：完整主问题能否自然读出，副文与Logo组是否有阅读先后；发际线、眼鼻口、头颈、托腮、持麦／道具接触处是否清楚，人物是否仍有足够近景尺度；主字是否被改形，标题是否压人或被人吞掉笔画，标识是否齐全，组间距与牌边是否舒服。不能把人物挤到角落给字让位。几何检查、字体文件存在和PNG可解码均不代替实际看图，也不证明身份相似、字形自然、审美或点击率。

同一条的封面、成片标题和四平台文案表达同一观看理由。发布包默认交当前成片、三比例最终封面、中文／英文／双语SRT、四份可复制文案、必要章节和使用说明；明示内嵌字幕状态，避免重复叠字幕。按[交付规范](qa-delivery-cleanup.md)核对文件及ZIP，保留当前可编辑源、身份／品牌依赖与有用实测证据。

只有用户明确要比较才另出方向；一旦选定，规范交付保留所选封面，确认无当前依赖的旧候选及独占派生可恢复移至Trash。实际人物摄影版、左人右文和被拒横向拉伸排版属于本案例的探索历史，不能与已选中央漫画版并列成默认。

下例脚本路径相对Skill根；在项目目录执行时，应解析为当前已安装Skill中脚本的绝对路径，不假设新项目也有同名`scripts/`目录。

```sh
python3 scripts/cover_overlay.py --config cover.json --output cover.png --measure cover-measure.json --overlay cover-info.png
```

helper需要Pillow，只接受已经组成目标原生比例的底图与透明PNG标识；底图分辨率不同时仅等比缩放，不硬裁或改变比例，不擅自装依赖或联网。主字与副文可在`text`中用自然换行；所有行都按真实字形中心对齐。`keepouts`必须来自本图的真实关键区域，不能套用上一条嘉宾坐标。工具遇到缺标识、字形非自然比例、文字／Logo互撞、越安全区或压到关键区域会报错，让制作者重新布局；不会靠缩扁文字或删除标识来自动过检。
