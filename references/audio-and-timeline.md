# 原声精剪、声画EDL与词锚点

## 全片自然精剪

收到完整剪辑授权后，检查所有发言者，不能只修用户指出的一句、只改主持人或只改字幕。找词式复述、同义但无新增意思的重说、未完成后重新起头的半句、明显口吃可精简；按功能保留真正回答、彼此确认、强调、产品名必要复现、唤醒词、笑声、换气与成立条件。不要机械删除所有“嗯／啊／然后”。

对每个候选保留“删什么／为什么／保住什么”及源前后上下文。ASR可能折叠重复，也可能在过短窗口幻觉；用宽上下文、原音定位与词锚点交叉判断。用户耳听纠正必须对照真实原音，不把用户说“充了重复”改记成产品名重复。没有主观耳听时明确这一限制，不把ASR或波形边界叫作“已经听顺”。

切口优先无发声或不破坏音素的位置，保住句头与尾音。极短边缘淡变可防点击，但不能混掉字头或偷改时长；淡变长度、响度目标和处理方法随本期素材选择，不沿用案例固定值。已冻结声音只作视觉返修时，不重新标准化响度、提速或叠话。

## 声画同cut与动作连续

先做原声EDL，再让对应画面剪去同一源区间。检查源接缝两侧手势、口型、身体与视线；音频变顺但手部瞬移仍是未修完。镜头切近可以是诚实且自然的机位交接，不能把“只挪camera”当成修复真实源断点。回原片寻找连续起点／完整句尾、扩大上下文或调整切法；不恢复已去的口吃来凑动作，不合成新动作或新发言。

## 一套当前时钟

输出帧是主时钟。保存：

| 数据 | 必要信息 |
| --- | --- |
| 源索引 | 稳定ID、真实路径、源帧率／时基、总长、来源与排除范围 |
| EDL实例 | 独立实例ID、源ID、半开入出范围、输出起点、速度、用途；同一源用于钩子和正文是两个实例 |
| 字幕 | 当前入出点、真实原话、发言者、可能跨多个EDL的 `source_ranges` |
| 词锚点 | 当前发声起止、对应字幕与源范围、定位依据及疑点 |
| 强调 | 真实短语、指向的词、实际发声锚点、动画时长与句末保持 |
| 视觉／声音事件 | 镜头、身份、Header、图解、红章、SFX、总结、预告及章节的当前锚点和语义作用 |

先锁声音与映射，再制作其余层。删段后不能全片减同一个秒数；只有确实统一删首时才可统一平移。累积删段一次作用于明确旧基准，不反复扣到已经缩短的时间轴。当前EDL与辅助旧锚点映射要区分，不能维护两套相互竞争的实际剪辑。

对原速保留段，`输出帧 = 该EDL输出起点 + 源帧 - 源入点`。相同源帧可出现多次，调用方必须指定EDL实例。精确词锚点落入删段时应报错并回源决策，不能悄悄吸附到接缝、拉长静音或延长口型。仅非语音装饰旧锚点允许按明确策略折叠到边界，并检查零长事件与上下文。

不同源帧率、变速或VFR素材必须先明确时间基、重采样和音画映射，再验证。不要把浮点显示的6位小数当作累计计算依据。

## 可执行检查

从[中立示例](../assets/timeline.example.json)复制数据结构，换成本期真实数据；示例对白是虚构的结构演示，不是可剪素材。以下脚本路径相对于本Skill根目录；在项目中调用时解析为已安装脚本位置，不把脚本复制成第二套。用：

```text
python3 scripts/timeline_guard.py validate <timeline.json>
python3 scripts/timeline_guard.py validate <timeline.json> --check-files --require-lock
python3 scripts/timeline_guard.py map <timeline.json> --edl-id <instance-id> --source-frame <integer>
```

辅助器只支持同CFR、原速整数帧EDL，不代替其它工程的完整时基处理。它检查源边界、无洞无叠覆盖、样本数、身份引用、字幕／词边界、逐段源映射、强调词锚点及互斥视觉窗口。`identity`、`header`、`summary`、`teaser`四类自动归入 `primary_information`互斥组，漏填不会逃过检查，也不能改组来制造重叠。`--check-files`只证明文件存在，不读音画；`--require-lock`要求生产声音锁定。输出成功也不证明语意正确、字幕识别准确、切口自然或实际听审完成。

映射完成后重新检查所有受影响层与交付字幕／章节。必要输入发给并行制作人员时带修订号、时长和哈希；单人发布共用时钟，其他人只读，自己的视觉分支隔离。处理软链或硬链接前确认写入是否会改到共享目标。
